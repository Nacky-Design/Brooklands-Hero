# DIS / HERO — контактная тень, проход 01

Текущая GLB — временная. Качество автомобиля не принято; до его замены клиентский показ не считается готовым.

## Изменение

Новый `src/ContactShadow.jsx` строит контактную тень от геометрии GLB. Камера проекции под полом выбирает ближайшие к земле поверхности; тень затухает по высоте. Плотная составляющая удерживается у контактов, мягкая — под кузовом. На пол больше не проецируется прежний размытый силуэт от directional shadow map. Самозатенение автомобиля сохранено.

Маска 512 × 512, два локальных Gaussian blur-прохода, без новых зависимостей и без полноэкранной постобработки. Карта пересчитывается после изменения фактического поворота машины и кэшируется в покое. GPU-ресурсы и обработчики освобождаются при размонтировании. Исходная модель, её материал, камера, освещение, архитектура и интерфейс не менялись.

## Артефакты

- `comparison.png` — до / новый вариант тени.
- `before-1920x1080.png`, `after-1920x1080.png` — desktop.
- `before-430x932.png`, `after-430x932.png`, `rotated-430x932.png` — mobile и поворот.
- `qa-results.json` — существующие сценарии, повторены 430 и 1920 px; оба PASS, включая восемь углов, drag, клавиатуру, тач и fallback.
- `qa-shadow.json` — пересчёт при вращении, кэширование в покое, отсутствие console/shader errors, потеря WebGL-контекста — PASS.
- `qa-production-loading.json` — загрузка и управление в production под `/Brooklands-Hero/` — PASS.

Остальные размеры в этом проходе повторно не запускались: layout/камера неизменны, предыдущая полная матрица сохранена в `artifacts/composition-01/qa-results.json`. Производительность на физических GPU и телефонах не проверена. Оптимизация кэширования не является подтверждением высокого FPS при вращении.

Команды: `QA_WIDTHS=430,1920 QA_RESULTS_PATH=artifacts/shadow-01/qa-results.json node scripts/qa.mjs`, `node scripts/qa-shadow.mjs`, `node scripts/compare-shadow.mjs`, `npm run build`.

Это промежуточный вариант для рабочей оценки сцены. После замены GLB контакт и мягкость тени нужно повторно проверить. Целевой визуал и клиентская готовность не утверждены.
