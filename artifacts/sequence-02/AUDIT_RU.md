# BROOKLANDS — аудит ракурсов / Sequence 02

Проверены все 24 ракурса. Проблема уменьшения сбоку подтверждена: ширина исходного силуэта почти фиксирована генератором, но вертикальный диаметр шин и высота кузова меняются. Одинаковая рамка в плеере не компенсировала разную дистанцию камеры в исходниках.

Внесены индивидуальные равномерные scale + X/Y shift. Размер исходных файлов, альфа-канал и их пиксели не редактировались; растяжения только по одной оси, повторной генерации и морфинга нет. Масштаб стартового 00 принят за опорный. При переходе к боку сохраняется естественное увеличение видимой длины.

Опорные точки вручную отмечены на исходных кадрах: верх и низ ближней видимой шины (приблизительная точность ±6 px). Горизонтальное выравнивание — по середине непрозрачного силуэта, вертикальное — по нижней опорной точке. Это практическая регистрация изображений, не восстановленная физическая ось вращения. Для 09/21 шины закрыты кузовом: масштаб оценён интерполяцией высоты уже откалиброванных соседних силуэтов. Точное восстановление единой камеры по этим данным невозможно.

Разброс высоты непрозрачного силуэта (отношение максимума к минимуму минус один) до: 550–755 px, **37.3%**; после: 669.6–709.6 в координатах опорного холста, **6.0%**. Это показатель изменения экранного размера, а не доказательство точности перспективы. Совпадение выбранных опорных точек пола является результатом регистрации; физическая достоверность теней этим не подтверждается.

Мобильный и узкий настольный viewport используют один общий масштаб для всех кадров, рассчитанный по самой широкой исправленной проекции, включая альфу >16. Кадр не подгоняется заново при каждом повороте. На desktop оставлено место для правых карточек. Поэтому стартовый автомобиль на телефоне меньше прошлой версии: запас нужен для полного бокового вида без обрезки.

## Проверка и материалы

- `audit.json` — измерения, коэффициенты и границы всех 24 кадров.
- `audit.html` — все 24 пары до/после; раздавать из корня репозитория HTTP-сервером, относительные ссылки используют public/assets.
- `side-before-after.png` — сравнение старта и боковых кадров при одинаковом масштабе просмотра.
- `qa-calibration.json` — production под /Brooklands-Hero/, 24 кадра на каждом из 7 размеров: 320 × 812, 430 × 932, 900 × 760, 1440 × 900, 1536 × 864, 1920 × 1080, 2048 × 1152. Проверяются реальная DOM-трансформация изображения, равномерный scale, опорная высота, отсутствие обрезки видимой альфы, место для правых карточек и замыкание цикла.
- `player/qa-results.json` — регрессия плеера на шести размерах, мышь / клавиатура / touch CDP, задержки и ошибки сети с повтором загрузки. Проверена перед последней правкой только общей зоны desktop; финальная матрица геометрии выполняется на итоговой сборке.
- `hero-*-frame*.png` — скриншоты старта, боков, фронта, заднего вида и стыка.

Исходный GLB, WebP и PNG не изменены. Физические телефоны, Safari и публичный Pages из облачной среды не проверены; доступ к домену Pages ограничен сетевой политикой. Публикация подтверждается Git push в gh-pages. Финальное утверждение качества остаётся за арт-директором.
