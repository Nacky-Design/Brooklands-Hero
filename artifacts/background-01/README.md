# DIS / HERO — чистый фон + GLB, проход 01

## Основание и подход

Прямое указание арт-директора заменяет прежнее требование 3D-помещения: сгенерировать чистый архитектурный фон из утверждённого изображения и поставить поверх настоящую GLB. Исходные `CODEX_PROMPT.md`/`QA_CRITERIA.md` сохранены, актуальное уточнение записано в README. Модель временная; клиентская готовность не заявляется.

`image_gen` удалил автомобиль, его тень/отражение и весь UI из утверждённого визуала, восстановив скрытую среду. Чистый исходник 1672 × 941 сохранён в references; WebP ~91 KB используется локально через HTML image preload. Нет второго автомобиля или изображения авто в фоне.

В Canvas только GLB, свет и контактная тень. Canvas прозрачен. Текст и UI остаются HTML/CSS. Предыдущая геометрическая Architecture удалена из приложения. Камера фиксирована; на мобильных низкий ракурс и сдвиг компенсируют линию пола кадрированного фона.

## Проверки

- Сборка — PASS, предупреждение о размере основного JS-бандла сохраняется.
- `qa-base-matrix.json`: исходный прогон всех шести размеров — PASS по функциональным критериям.
- После визуальной коррекции опоры на мобильных повторены 320/430, вращение, тач, fallback/reduced motion — PASS (`qa-mobile-alignment.json`). Desktop camera/interaction при этой коррекции не менялись.
- `qa-results.json` — объединённые прошедшие результаты desktop из base-прогона и mobile из повторного; поле `sourceRun` сохраняет происхождение.
- `qa-background.json` — PASS: фон запрошен один раз как preload, Canvas с alpha; его скрытие убирает машину, сохраняя фон; при повороте изменяются пиксели машины, пиксели фона и камера статичны; console errors отсутствуют. Без WebGL остаётся чистая среда и читаемый fallback.
- `qa-production-loading.json` — проверка production под `/Brooklands-Hero/`.
- Целевые физические GPU/FPS и внешний CDN из среды — NOT VERIFIED. Публичный домен блокируется сетевой политикой среды; push сборки проверяется отдельно.
