# Brooklands — пакет для браузерного Codex

## Состав
- `model.glb` — исходная модель, полученная из Tripo, НЕ изменена.
- `hero-approved.png` — утверждённый статичный HERO, только визуальный референс.
- `CODEX_PROMPT.md` — полный промпт для Codex.
- `QA_CRITERIA.md` — критерии тестирования и признаки неудачи.

## Как начать (работа в браузере, без локальных программ)
1. Создайте отдельный GitHub-репозиторий (`brooklands-hero`) или используйте существующий репозиторий только этого проекта.
2. Распакуйте ZIP на компьютере. В GitHub → Add file → Upload files загрузите `model.glb`, `hero-approved.png` (в корень для начала — нормально). Коммитните изменения.
3. В Codex выберите облачную среду, связанную с этим репозиторием. Если опубликованной среды ещё нет, создайте и опубликуйте её для этого репозитория. Локальные Node/Python/Docker не нужны.
4. В задачу Codex вставьте текст `CODEX_PROMPT.md`. Файлы должны быть доступны Codex из GitHub; просто загружать ZIP в репозиторий вместо распаковки не рекомендуется.
5. Codex сам организует пути, установит зависимости, создаст Vite+React при пустом репозитории и покажет результат проверки.

## Важно
- `hero-approved.png` — 1672×941, НЕ настоящий 1920×1080; это референс для оформления. Отдельно проверить реальный viewport 1920×1080.
- В модели один mesh и один материал, поэтому независимые цвета кузова, зеркал, дисков и тонировки в этом тесте НЕ реализуем.
- 4 исходных снимка Tripo и GIF вращения не нужны.
