# BROOKLANDS — HERO / покадровый прототип

[Опубликованный HERO](https://nacky-design.github.io/Brooklands-Hero/).

Текущая итерация по прямому указанию пользователя заменяет GLB на 24 сгенерированных опорных ракурса поверх неподвижного архитектурного фона. Это изменение ранее заданного требования настоящего 3D; `CODEX_PROMPT.md` и `QA_CRITERIA.md` сохранены как исходные документы. Сейчас приложение показывает изображения, не WebGL.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Мышь / горизонтальный свайп переключают кадры; кнопки и стрелки клавиатуры — один кадр, Home при фокусе сцены возвращает исходный. После последнего кадра снова первый. Автовращения нет. Пресеты остаются макетом; форма и навигация показывают демо-сообщение.

Первый кадр загружается и декодируется отдельно. После его отображения два фоновых загрузчика скачивают остальные кадры, начиная с соседних. При ожидании или ошибке сохраняется последняя доступная картинка; предусмотрен повтор загрузки. Устаревший ответ не подменяет новый выбранный кадр. В памяти хранятся сжатые Blob, а не 24 декодированных Image.

`public/assets/turntable-v1/` — 24 WebP, quality 94, alphaQuality 100, без изменения размеров: суммарно 5 167 150 байт, первый 228 014 байт. WebP — сжатые веб-копии, не побайтовые PNG-оригиналы. Источники и архив сохранены отдельно в deliverables текущей рабочей среды. Manifest фиксирует размеры и целевые углы. Исходный GLB сохранён в `public/assets/model.glb`, приложение его не запрашивает. Фон — `atelier-background.webp`, происхождение описано в `references/atelier-empty-generation.md`.

Проверка production-сборки под префиксом репозитория:

```sh
QA_URL=http://127.0.0.1:4200/Brooklands-Hero/ node scripts/qa-sequence.mjs
```

На этом адресе нужно предварительно раздать содержимое dist из папки Brooklands-Hero. Результаты и скриншоты: `artifacts/sequence-01/`. Нужен Chromium (`CHROMIUM_PATH`, по умолчанию `/usr/bin/chromium`). Старые scripts/qa*.mjs и отчёты других итераций описывают прошлую GLB-версию и не проверяют текущий плеер.

24 кадра — раскадровка для оценки. Фактические углы не откалиброваны; есть близкие позы, изменения формы, дисков, света и теней. Переходы дискретные, шов последнего и первого ракурса видим. Плавное согласованное вращение и окончательное соответствие референсу не заявляются. Физические телефоны и Safari не проверены. Финальное решение остаётся за арт-директором.

Исходники приложения — ветка `brooklands-hero-spike`; готовая статическая сборка публикуется в `gh-pages` с `.nojekyll`. Публичный URL из этой облачной среды блокируется сетевым прокси; локально проверяется тот же production build с префиксом `/Brooklands-Hero/`.
