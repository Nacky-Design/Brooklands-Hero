# BROOKLANDS — HERO / покадровый прототип

[Опубликованный HERO](https://nacky-design.github.io/Brooklands-Hero/).

Текущий тест Sequence 03: **25 кадров** (исходные 24 + кандидат 01b между 01 и 02), общий обратимый цветкор фона и автомобиля. [Сравнение цвета и тест перехода](https://nacky-design.github.io/Brooklands-Hero/review.html). На странице сравнения есть три варианта обработки, старт / бок / задний вид и повторение 01 → 01b → 02 → 01b. В основном HERO автоповторения нет.

Текущие исходники порядка и масштаба — `src/sequenceManifest.json`; фильтры — `src/ColorGrade.jsx`. [Цветовой ориентир](references/sequence-03/COLOR_REFERENCE.md), [происхождение кандидата и ограничения](references/sequence-03/GENERATION.md). Кандидат не подтверждает точный промежуточный угол и сохраняет дрейф деталей, особенно спойлера. Исходные файлы серии и фона не изменены. Все дальнейшие упоминания 24 кадров и Sequence 02 описывают основание этой версии.

Актуальные проверки (при запущенном production-сервере):

```sh
QA_URL=http://127.0.0.1:4203/Brooklands-Hero/ node scripts/qa-sequence03.mjs
QA_URL=http://127.0.0.1:4203/Brooklands-Hero/ node scripts/qa-sequence03-network.mjs
```

Результаты и скриншоты — `artifacts/sequence-03/`. Проверены 25 изображений на 320 / 430 / 900 / 1440 / 1920 px, клавиатура, мышь, touch CDP, страница сравнения, три кадра в обе стороны и восстановление сетевых ошибок. Ранние qa-sequence.mjs / qa-calibration.mjs рассчитаны на прежнюю 24-кадровую версию и служат историей.

Текущая итерация по прямому указанию пользователя заменяет GLB на 24 сгенерированных опорных ракурса поверх неподвижного архитектурного фона. Это изменение ранее заданного требования настоящего 3D; `CODEX_PROMPT.md` и `QA_CRITERIA.md` сохранены как исходные документы. Сейчас приложение показывает изображения, не WebGL.

Текущая коррекция Sequence 02: для каждого ракурса добавлены равномерный масштаб и смещение по опорным точкам шин. Боковые виды увеличены на 23–27%; разброс высоты силуэта уменьшен с 37% до 6%. [Полный аудит](artifacts/sequence-02/AUDIT_RU.md), [сравнение до/после](artifacts/sequence-02/side-before-after.png). `references/sequence-landmarks.json` хранит ручные измерения, `src/frameCalibration.json` — рассчитанные поправки. Изображения не пересчитываются: преобразования применяются только при показе. Общий масштаб viewport одинаков для всех кадров; на телефоне оставлен запас для самой широкой боковой проекции.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Мышь / горизонтальный свайп переключают кадры; кнопки и стрелки клавиатуры — один кадр, Home при фокусе сцены возвращает исходный. После последнего кадра снова первый. Автовращения нет. Пресеты остаются макетом; форма и навигация показывают демо-сообщение.

Первый кадр загружается и декодируется отдельно. После его отображения два фоновых загрузчика скачивают остальные кадры, начиная с соседних. При ожидании или ошибке сохраняется последняя доступная картинка; предусмотрен повтор загрузки. Устаревший ответ не подменяет новый выбранный кадр. В памяти хранятся сжатые Blob, а не 24 декодированных Image.

`public/assets/turntable-v1/` — 24 WebP, quality 94, alphaQuality 100, без изменения размеров: суммарно 5 167 150 байт, первый 228 014 байт. WebP — сжатые веб-копии, не побайтовые PNG-оригиналы. Источники и архив сохранены отдельно в deliverables текущей рабочей среды. Manifest фиксирует размеры и целевые углы. Исходный GLB сохранён в `public/assets/model.glb`, приложение его не запрашивает. Фон — `atelier-background.webp`, происхождение описано в `references/atelier-empty-generation.md`.

Проверка production-сборки под префиксом репозитория:

```sh
QA_URL=http://127.0.0.1:4200/Brooklands-Hero/ node scripts/qa-sequence.mjs
```

На этом адресе нужно предварительно раздать содержимое dist из папки Brooklands-Hero. Результаты текущей геометрии и скриншоты: `artifacts/sequence-02/`; история первой установки: `artifacts/sequence-01/`.

```sh
QA_URL=http://127.0.0.1:4201/Brooklands-Hero/ node scripts/qa-calibration.mjs
```

`node scripts/audit-sequence.cjs` пересчитывает поправки по ручным опорным точкам (для этого вспомогательного инструмента нужен sharp; приложение и обычная сборка от него не зависят). Проверка плеера принимает `QA_RESULTS_DIR`, чтобы сохранять новый результат отдельно от истории. Нужен Chromium (`CHROMIUM_PATH`, по умолчанию `/usr/bin/chromium`). Старые scripts/qa*.mjs и отчёты других итераций описывают прошлую GLB-версию и не проверяют текущий плеер.

24 кадра — раскадровка для оценки. Фактические углы не откалиброваны; есть близкие позы, изменения формы, дисков, света и теней. Переходы дискретные, шов последнего и первого ракурса видим. Плавное согласованное вращение и окончательное соответствие референсу не заявляются. Физические телефоны и Safari не проверены. Финальное решение остаётся за арт-директором.

Исходники приложения — ветка `brooklands-hero-spike`; готовая статическая сборка публикуется в `gh-pages` с `.nojekyll`. Публичный URL из этой облачной среды блокируется сетевым прокси; локально проверяется тот же production build с префиксом `/Brooklands-Hero/`.
