# BROOKLANDS — HERO / Technical Spike

Рабочий прототип по DIS: чистый архитектурный фон и настоящий вращаемый Porsche в GLB.
Актуальное указание арт-директора — генерировать фон без автомобиля, текста и UI, а автомобиль размещать отдельным WebGL-слоем. Это уточнение имеет приоритет над исходными требованиями `CODEX_PROMPT.md` о геометрии окружения.

Текущая GLB — временный ассет. Её замена обязательна до клиентского показа. Визуал и типографика остаются на оценке арт-директора.

## Запуск

Node.js 22.12+ (проверено на 24.22.1), npm. Исходники находятся в ветке `brooklands-hero-spike`.

```sh
cd /workspace/Brooklands-Hero
npm ci
npm run dev -- --port 5173
```

Страница: http://localhost:5173/ (Vite слушает 0.0.0.0).

```sh
npm run build
npm run preview -- --port 4173
```

Публичный рабочий прототип: https://nacky-design.github.io/Brooklands-Hero/ — после успешного Pages deployment ветки `gh-pages`.

## Слои композиции

- `references/atelier-empty-generated.png` — сгенерированная чистая среда 1672 × 941. Автомобиль, его тень/отражение, тексты, логотипы, карточки и круговая разметка удалены. Архитектура и свет следуют утверждённому референсу.
- `public/assets/atelier-background.webp` — оптимизированная веб-версия, 91 140 байт, загружается preload из HTML. Отдельных генераторов или инструментов кодирования при сборке не требуется.
- `public/assets/model.glb` — исходная модель, не изменена. Canvas прозрачен; в нём находятся автомобиль, свет и контактная тень.
- HTML/CSS — существующие меню, H1, CTA, статичный макет пресетов и управление. В фон интерфейс не запечён.

Камера и фон неподвижны. Перетаскивание мышью/пальцем вращает автомобиль; кнопки дают поворот на 45° и доступны с клавиатуры (Tab, Enter, Space). Автовращения нет. При reduced motion поворот применяется без damping. Вне зоны модели мобильная прокрутка сохраняется.

На desktop фон заполняет HERO; на мобильных имеет отдельную зону, кадрируется с фокусом 65% по горизонтали. Низкая камера и вертикальный сдвиг подгоняют машину к линии пола. Геометрическое 3D-помещение исключено из текущего рендера.

Canvas работает по необходимости: в покое нет непрерывного рендера. При отсутствии WebGL 2 остаются чистая среда и явное сообщение; автомобиль картинкой не подменяется.

Пресеты Original / Satin / Bespoke — статичный интерфейс. Смена материалов и форма заявки не подключены; навигация и CTA показывают демо-сообщение.

## Проверки

```sh
QA_RESULTS_PATH=artifacts/background-01/qa-results.json node scripts/qa.mjs
node scripts/qa-background.mjs
node scripts/compare-background.mjs
```

Требуется работающий dev-сервер 5173 и Chromium (`/usr/bin/chromium` в этой среде; `CHROMIUM_PATH` задаёт другой путь). `QA_URL`, `QA_WIDTHS` и `QA_RESULTS_PATH` позволяют выбрать адрес, ширины и файл результата основной матрицы.

Проверяются реальные запросы GLB, 360°, мышь/тач/клавиатура, viewport 320 / 430 / 1440 / 1536 / 1920 × 1080 / 2048, границы машины, overflow, fallback и console errors. Дополнительный тест проверяет прозрачность Canvas, отдельный рендер машины, неподвижность пикселей фона и единственный preload-запрос WebP.

Скриншот `artifacts/background-01/composite-no-ui-1920x1080.png` показывает только фон и GLB: UI скрыт исключительно для создания проверочного изображения, рабочая HTML-вёрстка сохранена.

Линтер не настроен. Физические iOS/Android и целевые GPU/FPS не проверялись. Источник фона 1672 × 941 масштабируется при реальном viewport 1920 × 1080; нативный Full HD исходник не заявляется.

## Основные файлы

- `src/main.jsx`, `src/style.css` — композиция, камера и взаимодействие.
- `src/StudioLighting.jsx` — свет для GLB поверх изображения.
- `src/ContactShadow.jsx` — контактная тень от реальной геометрии.
- `public/assets/` — локальные runtime-ресурсы.
- `references/hero-approved.png` — оригинальный утверждённый визуал, не загружается приложением.
- `references/atelier-empty-generation.md` — происхождение чистой среды.
- `artifacts/background-01/` — актуальные сравнения и проверки.
- `TECHNICAL_REPORT.md` — история итераций, результаты и ограничения.

## Ограничения и публикация

Статичный фон рассчитан на фиксированную камеру. Параллакс, перемещение камеры, динамические изменения света помещения и отражение вращающейся машины на полу не реализованы. Свет GLB и контакт подлежат повторной настройке после замены временной модели. Финальное совпадение с фотографичным референсом не заявляется.

Для GitHub Pages: Settings → Pages → Deploy from a branch → `gh-pages` → `/ (root)` → Save. Сборка из `dist/` публикуется в эту ветку вместе с `.nojekyll`; исходники редактируются в `brooklands-hero-spike`. Vite и URL ресурсов поддерживают путь `/Brooklands-Hero/`.
