# BROOKLANDS — VC-01 / 3D HERO Technical Spike

Ограниченный технический прототип по `CODEX_PROMPT.md` и `QA_CRITERIA.md`.
Это не финально утверждённый дизайн и не конфигуратор.

## Запуск

Node.js 22.12+ (проверено на 24.22.1), npm:

```sh
cd /workspace/Brooklands-Hero
npm ci
npm run dev -- --port 5173
```

Страница: http://localhost:5173/ (Vite слушает 0.0.0.0).
Для просмотра из облачной IDE откройте предпросмотр порта 5173, если он предоставлен интерфейсом.
Публичный хостинг этим проектом не развёрнут.

```sh
npm run build
npm run preview -- --port 4173
```

## Управление

Перетаскивание машины по горизонтали мышью / пальцем; кнопки поворота на 45° в обе стороны (Tab, Enter или Space). Камера, помещение и подиум неподвижны. Автовращения нет. При reduced motion поворот применяется без damping. На мобильных вертикальная прокрутка сохраняется; за пределами сцены обычное поведение страницы.

Пресеты — статичный макет, не кнопки изменения материалов. CTA и навигация показывают сообщение о демо, форма не подключена.

## Файлы

- `src/main.jsx` — интерфейс, загрузчик GLB, сцена, взаимодействие и fallback.
- `src/style.css` — адаптивная композиция.
- `public/assets/model.glb` — исходный GLB, байты сохранены.
- `references/hero-approved.png` — исходный референс, не используется приложением.
- `scripts/qa.mjs` — воспроизводимый браузерный smoke/interaction тест.
- `artifacts/` — скриншоты и результаты проверок.
- `TECHNICAL_REPORT.md` — результаты и ограничения.

## Браузерная проверка

```sh
# При работающем dev-сервере:
node scripts/qa.mjs
```

Требуется Chromium (`/usr/bin/chromium` в этой среде). Для другого пути задайте `CHROMIUM_PATH`; адрес сервера можно переопределить через `QA_URL`.
Проверки границ используют консервативную проекцию bounding box в dev-режиме, восемь углов через 45°, а не ручную оценку одного кадра. Тач проверяется CDP-вводом Chromium, не только вызовом JS-обработчика.
Линтер в минимальном проекте не настроен. Физические iOS/Android устройства не проверялись.

## Сравнение с референсом

Сохранены левый H1 и CTA, доминанта автомобиля справа/снизу, передний ракурс 3/4, компактные пресеты справа, серое архитектурное пространство и низкий подиум. Мобильная композиция пересобрана в вертикальную.

Свет и архитектура упрощены; фототекстурные детали, свет из проёма, растительные тени и фотографии в карточках не воспроизводятся. PNG никогда не служит фоном. Модель Tripo имеет один материал, запечённые блики и несовершенную геометрию; материал с metalness 0 / roughness 0.9 сохранён. Фотореализм и независимая настройка деталей не заявляются. Шрифт временный, системный.

## Публикация для клиента — GitHub Pages

Готовая статичная сборка размещается в ветке `gh-pages`, исходный код — в `brooklands-hero-spike`.
В настройках репозитория **Settings → Pages → Build and deployment** выберите
**Deploy from a branch → gh-pages → / (root) → Save**.
Предполагаемый адрес после успешной активации Pages: `https://nacky-design.github.io/Brooklands-Hero/`.
Сам факт отправки ветки не подтверждает доступность сайта: дождитесь успешного Pages deployment.

При обновлениях: `npm ci && npm run build`, затем обновить содержимое ветки `gh-pages` из `dist/`, сохраняя `.nojekyll`.
Vite использует относительные URL; путь GLB также учитывает `BASE_URL`. Проверен production build под `/Brooklands-Hero/` с загрузкой модели и вращением.
