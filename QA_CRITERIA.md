# DIS / QA — Brooklands 3D HERO spike

## Must-pass
- [ ] Загружается реальный `model.glb` (не плоская картинка, не спрайты).
- [ ] На 360° вращается автомобиль; стены и окружение не вращаются.
- [ ] Мышь, тач и кнопки поворота реально работают.
- [ ] Нет задвоенного Porsche (запрет использовать `hero-approved.png` как фон).
- [ ] Размер 1920×1080 проверен, автомобиль и H1 не обрезаны.
- [ ] 320 и 430 px проверены, нет горизонтального скролла.
- [ ] Нет кикеров, золота и неподтверждённых элементов.
- [ ] `npm run build` проходит, нет ошибок загрузки GLB / критических console errors.
- [ ] Есть ссылка на работающий предпросмотр и отчёт PASS/PARTIAL/FAIL.

## Отложено, не делать в этом тесте
- Реальные независимые материалы для кузова, дисков, зеркал, стёкол.
- Настоящий конфигуратор и клиентский backend.
- Замена шрифта на финальный.
- Остальные страницы и блоки.
