# Итерация 13: исправление плоскости 04b, 05, 05b

Пользователь указал три ракурса с поднятым носом после предыдущей правки. Метод поворота всей 2D-картинки отклонён: он меняет наклон всех линий сразу и не исправляет внутреннюю перспективу. Выполнена новая генерация трёх прозрачных исходников с текущим Porsche, исходными ракурсами, соседними 04/06 и стационарным фоном шоурума как опорой плоскости. Прямая генерация, без внешнего research; новое художественное направление не создаётся.

Генератору задано опустить переднюю часть относительно опорного заднего колеса, сохранив высоту камеры, отсутствие roll, серебристый материал, низкую крышу, спойлер и свет. При подготовке добавлены только прозрачные строки/столбцы до 1672×941 и конверсия WebP94/alpha100. Масштаб только равномерный; калибровка по диаметру ближней задней шины375px и общей опорной высоте. CSS-поворотов, skew, независимого растяжения колёс нет.

Провенанс: 04b — exec-8af24196-5fd1-46e7-8f08-d8d81c85ddec; 05 — exec-9a48f178-b230-4c58-95f5-7e6ffb6c5362; 05b — exec-1e7135eb-f642-40ef-bed6-609e233b2f7c. Исходники сохранены здесь, производные в public/assets/turntable-v9. Старые изображения остаются для сравнения. Единственный изменённый файл приложения — sequenceManifest.json, ровно три записи; порядок и 33 кадра сохранены. SHA исходных public-ресурсов и UI/цветкора подтверждены в source-integrity.json.

Положение контактов шин измерено вручную с погрешностью ±6px. Их экранный угол меняется 2.6 → 3.4 → 4.5 → 5.4 → 8.7° для 04 → 04b → 05 → 05b → 06; это сравнительная оценка перспективы, не замер физического pitch. Старая пара05/05b имела примерно8.9/8.6°. Эти цифры не заменяют визуального просмотра сцены.

Статус художественного решения: кандидат на просмотр пользователя, не формальное одобрение. Impeccable и Playwriter не подключены; браузерные проверки — Playwright.
