# Sequence 03 — рабочий цветовой ориентир

Это вариант для сравнения, не окончательно утверждённый цвет. Проверяется на стартовом 00, боковом 02 и заднем 09, а также на новом кандидате 01b.

Три состояния доступны на отдельной странице review.html: исходный, только фон, фон + автомобиль. В основном HERO по умолчанию показан третий вариант. Управление сравнением не добавлено в основной интерфейс.

Фон: SVG feColorMatrix в пространстве sRGB. Выходные каналы: R = 0.98R + 0.005, G = 0.99G + 0.003, B = 1.025B + 0.002. Слегка нейтрализует тёплые светлые участки, сохраняя характер архитектуры. Альфа не меняется.

Автомобиль: saturation 0.94; затем гамма в sRGB: R = 0.96 × R^0.95, G = 0.955 × G^0.95, B = 0.945 × B^0.96. Приглушаются светлые участки и холодный оттенок; чёрный остаётся нулём. Альфа сохраняется. Это общая мягкая обработка, без отдельных масок фар, кузова или суппортов.

Параметры применяются после покадрового масштабирования одинаково ко всем 25 изображениям через src/ColorGrade.jsx. Исходные PNG, старые WebP и фон не изменены, повторного сжатия серии не было. Новый кадр имеет отдельную WebP-копию quality 94 / alphaQuality 100, как прежние.

Последующие ракурсы следует генерировать в исходной нейтрально-холодной тональности по необработанным PNG; затем применять тот же фильтр при показе. Если генерировать по уже обработанному варианту и снова накладывать фильтр, возникнет двойной цветкор.

Обработка не исправляет направления отражений, форму спойлера, угловой шаг и тени. В исходниках есть теневая подложка и разная перспектива; цвет не делает их физически согласованными. Цветовой ориентир может быть пересмотрен арт-директором.
